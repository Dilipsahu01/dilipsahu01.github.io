Full-Stack RAG · Privacy-First Completed
Challenge

Turn unstructured book data into searchable AI-powered knowledge without relying on any cloud AI APIs.

Approach

Selenium scraper → Django REST backend → ChromaDB vector store + MySQL relational metadata → Local LLM via LM Studio → Next.js frontend. Why ChromaDB: needed a vector database that could run locally alongside the LLM for zero-cloud-dependency semantic search.

Outcome

Full RAG ecosystem with semantic search, automated summaries, and genre classification — all running locally with zero cloud AI calls.

AI Candidate Ranking Pipeline

AI Engineering · CPU-Only Completed
Challenge

Rank 100K+ JSON resumes in under 5 minutes on CPU-only hardware without external APIs or GPU acceleration.

Approach

Three-stage funnel pipeline — vectorized Pandas filtering → BM25 lexical retrieval → all-MiniLM-L6-v2 semantic similarity. Each stage progressively narrows the candidate pool so the expensive embedding computation only runs on pre-filtered candidates.

Outcome

Processes 100K+ resumes in <5 minutes. Zero GPU, zero API costs. Deployed with Gradio UI.

Python Pandas Sentence Transformers BM25 Gradio

05

Handwritten Digit Recognition — Neural Network from Scratch

Core CS · Zero Frameworks Completed
Challenge

Understand neural networks at the mathematical level — no TensorFlow, no PyTorch, no frameworks whatsoever.

Approach

784→128→10 feedforward network in pure Java. Manual backpropagation with primitive arrays. Xavier initialization, Sigmoid + Softmax activations. Independently derived 1-bit quantization concept (pixel binarization: /255 → threshold 0.3 → binary).

Outcome

96% accuracy on MNIST with 10K-sample training. Persistent weights via brain.dat serialization. Interactive 28×28 Java Swing drawing canvas.

Core Java Java Swing MNIST MVC Pattern
